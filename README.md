# Python Calculator

[Python](https://www.python.org/)

This project was originally created with the objective of improving my Python skills, but over time it grew into something I was proud enough to publish on GitHub. Hopefully, this also brings me closer to getting my dream job at Microsoft.

## Features

- **Basic arithmetic**: Supports basic arithmetic.
- **Advanced math**: Supports math calculations such as `log()`, `sqrt()` and `sin()`.
- **History**: History of previous calculations stored in a .json file, which can also be cleared.

## Usage

```bash
python calculator.py
```

Follow the on-screen instructions to start using the calculator.
